# Security policy

Sidelobe takes security reports seriously.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a suspected vulnerability.

Email [hello@sidelobe.dev](mailto:hello@sidelobe.dev) with the subject `[Security]` and include, where possible:

- the affected repository, service or URL;
- a clear description of the issue and its potential impact;
- reproduction steps or a proof of concept;
- any relevant logs, screenshots or environment details;
- a safe way to contact you for follow-up.

We will review the report and coordinate disclosure and remediation directly with the reporter.

## Scope

Repository-specific security guidance takes precedence when a project provides its own `SECURITY.md`.
