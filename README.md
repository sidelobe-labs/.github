# Sidelobe organization metadata

This repository contains the public GitHub profile and shared community-health defaults for the Sidelobe organization.

## Structure

- `profile/README.md` — public organization profile shown at https://github.com/sidelobe-labs
- `profile/assets/` — public profile and avatar assets
- `SECURITY.md` — default vulnerability reporting guidance
- `CONTRIBUTING.md` — default contribution guidance
- `SUPPORT.md` — default support routes
- `CODE_OF_CONDUCT.md` — default community expectations
- `PULL_REQUEST_TEMPLATE.md` — default pull-request checklist
- `.github/ISSUE_TEMPLATE/` — default public issue templates

Canonical brand source files are maintained separately. The copies here exist only for public GitHub presentation.

Website: https://sidelobe.dev
